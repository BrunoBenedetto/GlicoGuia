# GlicoGuia

O GlicoGuia é uma aplicação web educativa que transforma leituras de glicemia em orientações simples e acolhedoras. Em vez de mostrar apenas um número, ela explica a faixa informada, sugere cuidados iniciais e destaca quando procurar atendimento de saúde.

## Funcionalidades

- Leitura de glicemia em mg/dL;
- Contexto da medição: jejum, duas horas após a refeição ou outro momento;
- Campos para idade, peso e frequência de atividade física;
- Orientações para glicose baixa, faixa esperada, pré-diabetes e glicemia elevada;
- Regra 15–15 para casos de hipoglicemia sem sinais graves;
- Alertas de urgência para sintomas importantes;
- Interface responsiva, pensada para pessoas de diferentes idades.

## Como executar

Não é necessário instalar dependências. Basta abrir o arquivo `index.html` em um navegador moderno.

```text
index.html
```

## Aviso importante sobre saúde

Esta ferramenta tem finalidade exclusivamente educativa e **não realiza diagnóstico**. Uma medição isolada em glicosímetro não confirma diabetes, pré-diabetes ou o grau de uma condição clínica.

Procure um(a) profissional de saúde para avaliação individualizada e exames laboratoriais, especialmente em caso de leituras alteradas repetidas, sintomas ou uso de medicamentos para diabetes. Em caso de desmaio, convulsão, confusão importante, dificuldade para respirar ou incapacidade de engolir, procure atendimento de urgência imediatamente.

As referências de interpretação apresentadas se baseiam em recomendações da American Diabetes Association e do CDC para glicemia e hipoglicemia.
